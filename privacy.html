Privacy Policy

Last updated: November 17, 2026

1. Overview

Xavier is a personal AI assistant used by a single owner on the owner's own computer. This policy explains what Google user data the application accesses and how it is handled.

2. Data accessed

With the owner's consent, Xavier requests these Google OAuth scopes:

  • https://www.googleapis.com/auth/gmail.readonly, gmail.send, gmail.modify (Gmail)
  • https://www.googleapis.com/auth/calendar (Google Calendar)
  • https://www.googleapis.com/auth/drive (Google Drive)
  • https://www.googleapis.com/auth/spreadsheets (Google Sheets)
  • https://www.googleapis.com/auth/documents (Google Docs)
  • https://www.googleapis.com/auth/contacts.readonly (Google Contacts)

3. How data is used

Data is accessed only to carry out tasks the owner explicitly requests, for example reading or updating a spreadsheet. It is not used for advertising, profiling or any other purpose.

4. Storage

The OAuth token is stored only on the owner's computer. The developer does not operate any server that receives, stores or processes Google user data.

5. AI processing

When the owner asks the assistant to work on some content, that content may be processed by the AI model service the owner has chosen to use for the assistant. No content is processed except at the owner's request.

6. Sharing

Google user data is not sold, and it is not shared with third parties except as described in section 5.

7. Google API Services User Data Policy

Xavier's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Revoking access and deleting data

The owner can revoke access at any time at myaccount.google.com/permissions and delete the locally stored token file from the computer.

9. Changes

This policy may be updated. The date above shows the latest revision.
